## Processing and provenance


User originals remain unchanged in `glb files/`. Runtime copies use Meshopt/WebP and 1024px textures for the unchanged hero assets and 128-768px textures on selected secondary assets. Legacy specular/gloss materials were converted where needed. The supplied runner retains its rig and walk animation. Source node selection extracts books, a single web, individual paintings and a cable without loading their full pack layouts into the scene.

The new window watcher retains all four complementary source meshes, with Meshopt/WebP compression and geometry simplification reducing 15.63 MB to 0.665 MB. The spider is a byte-for-byte copy of the supplied 26,468-byte download. Eight extra webs reuse the existing downloaded web asset; no creature or web GLB was generated.

The carved main desk uses the supplied museum table with its attached lamp trimmed away and dimensions adjusted. A second intact museum table forms the reading corner. The Victorian console retains its real drawer geometry. Both door assemblies retain their stone surrounds; both leaves can rotate for the scripted procession. One computer has two original clue IDs on different parts.

The original gothic window is copied byte-for-byte; its geometry/materials are preserved. The coat stand title says CC0, but its embedded license says CC-BY-4.0; the table above records the embedded license. Noncommercial/share-alike/no-derivatives/Standard terms are retained as supplied, not relabeled CC0. Lead-provided computer/torch provenance still needs original external attribution consolidated before public distribution.

The castle remains a medieval keep rather than a spired RE4 replica. It is now embedded in continuous forest terrain behind full leafy trees, distance mist and rain. Trees have separate near/far runtime copies. Standalone photographed floor/wall textures are not GLBs.

Superseded processed props were moved out of the public build to `scratch/study-assets/unused-runtime-copies/`; all original user files remain intact.

Current budget and graphics modes: [ROOM2_ATMOSPHERE_BUDGET_REVIEW.md](ROOM2_ATMOSPHERE_BUDGET_REVIEW.md). Books, cable and bin runtime packs now physically contain only their used source nodes; unmodified source downloads remain in `glb files/`.
